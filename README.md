# VeriSelect

A test-time best-of-N selector. Training-free.

> Status: repository skeleton. Code and data are being added incrementally.

## Structure

```
veriselect/
├── bench/        benchmark data and generators
├── verifier/     candidate scoring / verification
├── veriselect/   the core selection method
├── baselines/    alternative methods for comparison
├── eval/         evaluation
└── docs/         documentation and notes
```

## Setup

```bash
pip install -r requirements.txt
```

# bench

Benchmark data and generators, plus external benchmarks used for evaluation.

- `gamesolve/` — in-house GameSolve-Bench matrix-game data/generators.
- `GTBench/` — [jinhaoduan/GTBench](https://github.com/jinhaoduan/GTBench) as a git
  submodule (interactive game-theory benchmark). Brought in by `eval/setup.sh`.

See `eval/README.md` for how these are used in the Qwen3 scaling evaluation.
